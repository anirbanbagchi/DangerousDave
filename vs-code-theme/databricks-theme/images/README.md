# images

Screenshot placeholders referenced by the top-level [README](../README.md):

| File | Shows |
| --- | --- |
| `light.png` | Databricks Light — editor + side bar + status bar + terminal |
| `dark.png` | Databricks Dark — same view |
| `icon.png` | 128×128 Marketplace icon (add `"icon": "images/icon.png"` to `package.json` once it exists) |

decorators, f-strings and keywords are all visible in the frame.
